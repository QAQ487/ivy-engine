# Box2D

Vendored upstream Box2D v3.1.1 (MIT), unchanged src/include from the official release archive.
https://github.com/erincatto/box2d/releases/tag/v3.1.1

Engine projects compile C17 with BOX2D_DISABLE_SIMD for a scalar baseline.
